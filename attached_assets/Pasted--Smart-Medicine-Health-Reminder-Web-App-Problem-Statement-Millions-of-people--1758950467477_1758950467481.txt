💊 Smart Medicine & Health Reminder Web App


---

📝 Problem Statement

Millions of people — especially elderly and busy professionals — forget to take medicines on time.
Missing doses can cause serious health risks, but current solutions are either too complicated or not accessible to everyone.
Families also struggle to ensure that their loved ones are following prescriptions correctly.


---

💡 Solution

We built a Smart Medicine & Health Reminder Web App that makes medicine management simple and reliable:

1. Add medicines with name, dosage, and time.


2. Get automatic reminders via browser notifications when it’s time.


3. Mark each medicine as “Taken” or “Missed.”


4. View a history dashboard with adherence stats (taken vs missed).


5. (Optional stretch) Family members can view the schedule/logs through a secure share link.




---

⭐ Key Features

Medicine Scheduling → Add multiple daily medicines with dosage and time.

Smart Notifications → Browser notifications remind the user at the right time.

Taken/Missed Tracking → Users can log their status with one click.

History & Analytics → See daily/weekly logs and a chart of adherence rates.

Family Sharing (Basic) → Generate a link so family can check medicine status remotely.

Health Notes (Optional) → Add short notes (e.g., “Felt dizzy” or “Doctor stopped this dose”).

Dark Mode (Polish) → Modern UI experience.



---

🛠️ Tech Stack

Frontend: React.js + TailwindCSS (fast, modern UI)

Backend/Database: Firebase (Firestore for schedules, Authentication for users)

Notifications: Firebase Cloud Messaging (browser push notifications)

Charts/Analytics: Recharts or Chart.js

Hosting: Vercel / Netlify (instant deploy, easy demo)
